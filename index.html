Appy Meal kit

Helper files for Appy Meal, a Grok Bot template that builds your own private web app to replace an app you pay for, or to combine the 2-3 apps you juggle into one. Templates can't carry extra files, so the starter code, examples and build tools live here.

git clone --depth 1 https://github.com/Ryans-apps/appy-meal-kit
